# AGENTS.md

## Project

This repository contains the personal portfolio website of Noel Joe Basil.

The goal is to produce a premium-quality engineering portfolio showcasing experience in:

- Palantir Foundry
- AI Engineering
- Azure
- PySpark
- Python
- React
- NHS England
- Data Engineering
- Analytics Engineering

The website should feel similar to modern engineering sites from companies like Vercel, Stripe, Linear and Palantir.

---

## Tech Stack

Use only:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

Avoid introducing unnecessary dependencies.

---

## Design Principles

Prefer:

- Dark theme
- Glassmorphism
- Minimalism
- Clean whitespace
- Smooth animations
- Mobile-first layouts
- Accessibility
- Responsive components

Avoid:

- Bootstrap
- Material UI
- jQuery
- Bright colour palettes
- Cluttered layouts

---

## Code Style

- Functional React components
- TypeScript everywhere
- No `any` unless absolutely necessary
- Reusable components
- Small focused files
- Meaningful variable names

Prefer composition over duplication.

---

## Animations

Use Framer Motion.

Animations should be subtle.

No distracting effects.

Prefer:

- fade
- slide
- stagger
- scale
- opacity

---

## Performance

Optimise for Lighthouse scores.

Avoid unnecessary client components.

Prefer server components whenever possible.

---

## Images

Optimise images.

Compress large images.

Prefer SVG icons.

---

## Accessibility

Every interactive element should:

- support keyboard navigation
- have visible focus states
- include ARIA labels where appropriate

---

## SEO

Every page should include:

- metadata
- title
- description
- Open Graph tags

---

## Content

Do not invent achievements.

Only use information supplied from Noel Joe Basil's résumé or explicitly provided during development.

---

## Deployment

The application will be deployed to Azure Static Web Apps.

Ensure compatibility with static export where possible.

---

## Goal

Every change should make the portfolio look more premium while maintaining simplicity.
